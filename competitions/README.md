## 🚀 Como Executar Soluções

Você pode testar qualquer solução utilizando o helper CLI:
```bash
# Exemplo: Rodar o problema A da Seletiva UFABC 2026
./tools/cp run competitions/seletiva-ufabc/2026/A
```
