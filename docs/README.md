## ⚡ Setup Recomendado de Compilação (GCC)

No Linux / WSL, certifique-se de que possui o `g++` e `python3` instalados:

```bash
sudo apt update && sudo apt install -y build-essential g++ python3 wl-clipboard xclip
```
