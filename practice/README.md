# 🎯 Practice & Training Platforms

Problemas de treino organizados por plataformas e juízes online (Online Judges).

---

## 📁 Plataformas de Treino

| Plataforma | Divisões / Categorias | Conteúdo |
|---|---|---|
| [`codeforces/`](codeforces/) | `normal/` (Div 1 a 4), `greater/` (Edu, Global, UTPC), `special/` (Hello, Good Bye), `custom/` | 100+ problemas |
| [`atcoder/`](atcoder/) | `beginner/` (ABC), `regular/` (ARC), `grand/` (AGC), `heuristic/` (AHC) | 40+ problemas |
| [`vjudge/`](vjudge/) | Simulados virtuais e listas de treino (`2025-1`, etc.) | 10 problemas |
| [`leetcode/`](leetcode/) | Classificado por tópicos (`dynamic-programming/`, `graph/`) | 14 problemas |
| [`cses/`](cses/) | Problemas do CSES Problem Set | Download Speed, etc. |
| [`misc/`](misc/) | Aulas de DP clássica (GRUB), Programação Estruturada e criações | 17 problemas |

---

## 🚀 Como Criar e Rodar Novos Treinos

```bash
# Criar um novo round do Codeforces Div 3 com problemas A, B, C, D, E
./tools/cp new practice/codeforces/normal/div-3/round-1005 A B C D E

# Rodar e testar o problema A
./tools/cp run practice/codeforces/normal/div-3/round-1005/A
```
